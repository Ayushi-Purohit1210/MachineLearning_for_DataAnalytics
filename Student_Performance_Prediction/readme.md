# Project 01: Beginner Machine Learning for Data Analytics 

## Overview
This is the **first project** in the *MachineLearning_for_DataAnalytics* repository.  
It introduces the **basic machine learning workflow** used in data analytics, with a focus on clarity, simplicity, and concept-building.

This project is intentionally beginner-friendly and designed to help understand how data moves through an ML pipeline—from data loading to model evaluation.

(*Easy peasy lemon squeezy*)

---

## Objectives
- Understand the end-to-end ML pipeline  
- Learn how ML supports **data analytics**
- Practice:
  - Data loading
  - Feature–target separation
  - Train–test split
  - Model training
  - Model evaluation

---

## Tech Stack
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Jupyter Notebook
